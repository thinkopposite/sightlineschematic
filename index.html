3D model downloads: which format for what
.glb (glTF)The web standard for 3D. Opens in Windows 3D Viewer, PowerPoint (Insert › 3D Models), Blender and online viewers. For viewing and presenting; triangles only, no BIM data.
.ifc (IFC4)Open BIM. In Revit use Open › IFC, or Link IFC to coordinate. Each stand comes in as a slab (floor) and each precast aisle step as its own generic element, on a level per tier, with tier, stand, aisle, row, step type, riser, tread and width as parameters you can schedule, tag and filter. The geometry is fixed (not reshaped in Revit); for native editable Revit geometry use the Revit export with the Dynamo graphs. Also opens in Navisworks, Solibri, BIMcollab and other IFC viewers.
.3dm (Rhino)Rhino 7 / 8 and Grasshopper: one mesh per stand and per step, on layers by tier, named, with the same data as user text. Fully editable in Rhino. Revit imports .3dm (Insert › Import CAD) as fixed geometry; SketchUp Pro imports it through an extension.
.dae (SketchUp)Use Deliver › Export for SketchUp: opens with File › Import; stands as solids and the precast steps as components. Editable in SketchUp. (Still the full bowl: switched-off sections not yet taken out.)
3D viewer (.html)One file with this bowl inside: opens in any browser (rotate, pan, zoom, Perspective / Parallel, the four isometric views). Send it, or upload it to your website (for example your GitHub Pages repository, as bowl3d.html) and share that page's address; upload a new one after each change and the same link shows the update. Needs an internet connection the first time it opens (the 3D library loads from jsDelivr).
Units, originMetres; origin at the centre of the field at field level; Z up (glTF: Y up, converted by the viewer). Switched-off sections are left out of .glb, .ifc and .3dm.
